# 电子礼簿系统

一款**纯本地的单页 Web 应用，** 旨在为各类红白喜事提供一个现代化、安全、高效的礼金（份子钱）管理解决方案。它彻底告别了传统的手写礼簿，通过数字化的方式解决了记录、统计、查询和存档的全部流程，以**简单易用**为最高设计原则。

## 核心特性

### 数据主权，绝对安全

* **拔线能用**：纯 HTML 单页应用，无服务器交互，数据100%本地存储，不依赖任何云服务。
* **金融级加密**：全量数据采用 **AES-256** 加密落库（IndexedDB），管理密码 **SHA-256** 哈希保护。即便电脑丢失，文件被拷走也无法破解。

### 极致的录入体验

* **秒级记账**：姓名、金额、渠道（微信/支付宝/现金）全键盘操作，回车即录。
* **智能风控**：实时检测重名、重复金额，防止“记重了、记错了”。
* **自动大写**：输入数字，自动生成规范中文大写（如：壹仟元整）。
* **语音播报**：支持 TTS 语音朗读（“张三 贺礼 一千元整”），方便宾客现场核对金额，又能撑场面。

### 双屏互动 & 仪式感

* **访客副屏**：支持开启副屏页面，实时投射数据到外接屏幕/电视，主屏录入，副屏展示，方便现场宾客核对金额。
* **隐私脱敏**：副屏自动开启隐私模式，仅展示最新记录全名，历史记录自动打码。
* **收款码展示**：副屏支持自定义上传展示东家收款码，方便宾客现场扫码。
* **双色主题**：内置「喜庆红」与「肃穆灰」两套 皮肤，适应红白喜事不同场景。

### 专业级报表与归档

* **真·PDF 引擎**：内置 PDF 渲染器（非简陋的浏览器打印），支持**自定义字体、封面图、背景纹理**，生成精美的电子礼簿。
* **智能分批**：数据量超 1000 条自动分卷生成，防止浏览器内存溢出。
* **审计留痕**：全链路记录修改历史（时间轴），支持**软删除（作废）**，每一笔变动都有迹可循。
* **双重备份**：
  * **Excel**：标准 `.xlsx` 报表，含完整修改日志。
  * **数据文件**：导出加密的数据备份，支持跨设备全量恢复。

## 🚀 快速上手

---

### 启动：双击 gifts-book-server.exe（唯一方式）

本系统为保障数据安全，**强制通过附带的服务器运行**——直接双击 `index.html` 会因缺少 `data/` 自动备份保护而拒绝启动。

1. 从 [Releases](https://github.com/aisubing/gifts-book/releases) 下载 `gifts-book-complete-*.zip` 并解压；
2. 双击 `gifts-book/gifts-book-server.exe`，自动启动本地服务并打开浏览器（首次运行 SmartScreen 提示选"更多信息 → 仍要运行"）；
3. 端口默认 `8765`（被占用自动换空闲端口）；`-port` / `-dir` / `-addr` / `-open=false` 参数可选。

服务器为纯 Go 标准库单文件（无任何运行时依赖），源码见 [`server/main.go`](server/main.go)，交叉编译：`cd server && ./build.sh`。

### 初始化与记账

* 创建事项：填写事项名称与**管理密码**——密码即数据加密钥匙，**丢失无法找回**，请务必抄在纸上；
* 记账：姓名 + 金额，回车即录，全键盘操作；同名/同金额自动查重，支持语音播报与访客副屏；
* 事项名支持括号、全角标点等特殊字符。

### 归档：第一时间导出三样存档

记好后**第一时间**导出：**导出为 Excel**、**打印/另存为 PDF**，以及「备份/恢复数据」中的 **导出备份 (BIN)**——发微信收藏或存网盘。本工具定位现场记账，导出的存档才是最终归档。

### 本地自动备份（启动即自动启用）

* **自动落盘**：每次变更约 3 秒后，加密快照写入程序旁 `data/` 目录（AES 加密，与手动导出 BIN 格式完全相同）；
* **自动恢复**：换端口、换浏览器或清理浏览器数据后，用**相同的事项名和密码**重新进入即自动还原；亦可在「备份/恢复数据」中手动选择恢复；
* 多台电脑共用同一 `data/` 目录时请只在一端运行，避免备份互相覆盖；删除事项时其备份一并清理（删除流程强制先导出 Excel）。

### 导入外部礼单：gifts-book-makebin.exe

零依赖单文件工具（v1.3.2 起随完整包附带），把现成礼单整体变成新的电子礼簿：

1. 双击运行，选择礼单文件——**直接支持系统"导出为 Excel"的 .xlsx**（自动跳过空行、总计行与已作废记录，还原收款类型与宾客等级排序），也支持 UTF-8 编码 CSV；填写模板见 `tools/礼单模板.xlsx`；
2. 填写事项名称与管理密码，生成 `事项名.bin`；
3. 创建事项页点 **"选择 .bin 备份文件导入"**，选中文件、输入密码，整套礼单即导入为新事项。

亦支持命令行（`--list` 生成 / `--decrypt` 解密核对），源码见 [`tools/makebin`](tools/makebin)。

## 🧩 技术栈

* **Core**: Vanilla JS (ES6+), OOP 架构
* **Style**: Tailwind CSS
* **Database**: IndexedDB (idb wrapper)
* **Crypto**: CryptoJS (AES-256)
* **Export**:
  * `SheetJS` (Excel)
  * `PDF-Lib` & `Fontkit` (客户端 PDF 生成)
* **UI Components**: Grid.js (表格), RemixIcon (图标)

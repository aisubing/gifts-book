# 电子礼簿系统

一款**纯本地、零后端、完全本地运行的单页 Web 应用，** 旨在为各类红白喜事提供一个现代化、安全、高效的礼金（份子钱）管理解决方案。它彻底告别了传统的手写礼簿，通过数字化的方式解决了记录、统计、查询和存档的全部流程，以**简单易用**为最高设计原则。

> **本仓库（gifts-book）是 [gift-book](https://github.com/jingguanzhang/gift-book) 的优化 fork**，在上游基础上做了如下修复与增强（详见提交历史）：
>
> ### 数据安全与正确性
> * **备份导入跨密码修复**：将 A 密码的备份恢复到 B 密码的事项时，现在会自动以当前事项密码重新加密，此前会导致导入记录全部无法解密（空白格、统计为 0）。
> * **导入/删除原子化**：「清空旧数据 + 导入」与「删除事项全部礼金」合并为单个 IndexedDB 事务，部分失败自动回滚，不再出现旧数据已删、新数据不完整的永久丢失。
> * **写库以事务提交为准**：新增/更新/删除在事务真正落盘后才报告成功，配额满等异常不再"假成功"。
> * **懒解密与导出矛盾修复**：导出 Excel/PDF、统计、查重、搜索、副屏同步前自动补齐全量解密，修复大数据量刚进入事项时导出报错、重复告警失效、搜索漏结果等问题。
> * **解密失败不再静默**：失败记录保留密文并向用户提示条数，而非默默变成空白格。
> * **统计表行点击修复**：修正列索引错误，恢复"点击行查看详情"功能。
>
> ### 交互与体验
> * **录入防重复提交**：确认弹窗按住回车不会再连录多条相同礼金。
> * **键盘行为重做**：Esc 统一为"仅关闭弹窗"（不再误触作废等破坏性按钮）；弹窗内普通输入框回车不再代点确认；中文输入法组词回车不再误提交；密码框内回车即确认。
> * **密码弹窗可重试**：输错密码保持弹窗打开；X/Esc 关闭弹窗不再导致流程静默挂起。
> * **会话恢复失败不再白屏**：自动回到事项选择界面。
> * **副屏增强**：每页条数跟随主屏配置（6~24）自适应布局；主屏关闭/崩溃后显示"连接已断开"遮罩；设置弹窗打开时 Esc 只关弹窗；收款码在不支持持久化的环境下保存时明确提示。
>
> ### 其他
> * **XSS 加固**：姓名、备注、事项名等所有拼入 innerHTML 的用户数据统一转义；主副屏 postMessage 增加 origin/来源校验。
> * **导出文件名合法化**：Excel/JSON/BIN 文件名不再包含 `:` `/` 等 Windows 非法字符。
> * **性能**：BIN 备份导出去掉冗余的逐条解密+重加密；后台解密改为增量累计（原每批全量重建统计）；礼簿单元格生成减少一半重复计算；修复 blob URL 泄漏。
> * **清理**：移除误提交的空文件 `static/1`，修复打印标题模板、作废日志双标点等小缺陷。

## 核心特性

### 数据主权，绝对安全

* **拔线能用**：纯 HTML 单页应用，无服务器交互，数据100%本地存储，不依赖任何云服务。
* **金融级加密**：全量数据采用 **AES-256** 加密落库（IndexedDB），管理密码 **SHA-256** 哈希保护。即便电脑丢失，文件被拷走也无法破解。

### 极致的录入体验

* **秒级记账**：姓名、金额、渠道（微信/支付宝/现金）全键盘操作，回车即录。
* **智能风控**：实时检测重名、重复金额，防止“记重了、记错了”。
* **自动大写**：输入数字，自动生成规范中文大写（如：壹仟元整）。
* **语音播报**：支持 TTS 语音朗读（“张三 贺礼 一千元整”），方便宾客现场核对金额，又能撑场面。

### 双屏互动 & 仪式感

* **访客副屏**：支持开启副屏页面，实时投射数据到外接屏幕/电视，主屏录入，副屏展示，方便现场宾客核对金额。
* **隐私脱敏**：副屏自动开启隐私模式，仅展示最新记录全名，历史记录自动打码。
* **收款码展示**：副屏支持自定义上传展示东家收款码，方便宾客现场扫码。
* **双色主题**：内置「喜庆红」与「肃穆灰」两套 皮肤，适应红白喜事不同场景。

### 专业级报表与归档

* **真·PDF 引擎**：内置 PDF 渲染器（非简陋的浏览器打印），支持**自定义字体、封面图、背景纹理**，生成精美的电子礼簿。
* **智能分批**：数据量超 1000 条自动分卷生成，防止浏览器内存溢出。
* **审计留痕**：全链路记录修改历史（时间轴），支持**软删除（作废）**，每一笔变动都有迹可循。
* **双重备份**：
  * **Excel**：标准 `.xlsx` 报表，含完整修改日志。
  * **数据文件**：导出加密的数据备份，支持跨设备全量恢复。

## 🚀 快速上手

---

### 启动：双击 gifts-book-server.exe（唯一方式）

本系统为保障数据安全，**强制要求通过附带的服务器运行**——直接双击 `index.html` 时应用会拒绝启动并显示指引。

1. 从 [Releases](https://github.com/aisubing/gifts-book/releases) 下载 `gifts-book-complete-*.zip` 并解压；
2. 双击 `gifts-book/gifts-book-server.exe`——自动启动本地服务并打开浏览器；
3. 端口默认 `8765`（被占用自动换空闲端口）；`-port` / `-dir` / `-addr` / `-open=false` 参数可选。

**为什么强制？** 直接双击 `index.html` 时，数据仅保存在浏览器内部：清理浏览器数据、更换浏览器、更换端口都会导致数据无法访问，且没有 `data/` 本地自动备份兜底，PDF-LIB 精细打印引擎也不可用。礼金数据无价，系统在此类方式下会直接停止运行。

服务器为纯 Go 标准库单文件（无任何运行时依赖），源码见 [`server/main.go`](server/main.go)，交叉编译：`cd server && ./build.sh`。

### 本地自动备份（启动即自动启用）

通过上述服务器运行时，数据会在浏览器之外多一层保障：

* **自动落盘**：每次录入/修改/作废等变更后约 3 秒，自动把该事项的加密快照写入程序旁 `data/` 目录（文件如 `婚礼_event1.bin`，与手动导出的 BIN 备份格式完全相同，AES 加密）；
* **自动恢复**：换端口、换浏览器或清理浏览器数据后，只需用**相同的事项名称和密码**重新进入，系统会检测到 `data/` 下的同名备份并自动还原；
* **手动恢复**：菜单「备份/恢复数据」中可查看本地备份文件列表并一键恢复；
* **安全**：数据本身 AES 加密；API 仅接受本机访问，拒绝跨源读写；
* 删除事项时对应的备份文件一并清理（删除流程本身已强制先导出 Excel）。

未通过服务器运行（双击 index.html、普通静态服务器等）时，应用会显示数据风险说明并**拒绝启动**——这是防止用户在无备份保护的状态下记账的强制措施。

### 初始化

* 设置事项名称及**管理密码**（请务必牢记，丢失无法找回）。

### 记账与归档

* 录入数据（姓名、金额全键盘操作，回车即录）。
* 活动结束后，务必导出 **Excel** 或 **PDF** 到电脑，微信收藏或云盘永久保存。

## 👨‍💻 开发者指南

**本项目原生基于** **Vanilla JS + HTML** **开发，结构简单，开箱即用。**

### 1. 获取代码 (Git)

**首先将仓库克隆到本地：**

```
# 克隆项目
git clone https://github.com/aisubing/gifts-book.git

# 进入目录
cd gifts-book
```

### 2. 环境准备

需要 [Go](https://go.dev/dl/)（编译本地服务器）和一个代码编辑器（推荐 **VS Code**）。应用强制通过自带服务器运行（数据安全闸门），双击 `index.html` 无法进入系统。

### 3. 启动开发

```bash
# 编译并运行本地服务器（Windows 下生成 .exe）
cd server && go build -o gifts-book-server.exe . && ./gifts-book-server.exe
# 自动打开浏览器；或手动访问 http://localhost:8765
```

修改 `index.html` / `static/` 后刷新浏览器即可生效；修改 `server/main.go` 后重新编译。

### 4. 项目结构

* `index.html`: 主入口（核心代码均内嵌于此）。
* `server/`: 本地服务器（数据落盘 API + 静态伺服）。
* `static/`: 静态资源目录。
  * `tailwindcss.js`: 样式引擎。
  * `xlsx.full.min.js`: Excel 导出库。
  * `pdf-lib.min.js`: PDF 生成引擎。
  * `crypto-js.min.js`: 加密库。
  * `fontkit` & `.ttf`: 字体文件（用于 PDF 生成）。
* `guest-screen.html`: 副屏显示页面。

### 5. 部署说明

本应用为**本地应用**，不支持部署到 GitHub Pages / Vercel 等云端静态托管（数据落盘 API 必须与本机文件系统配合，且仅接受本机访问）。在单台电脑上通过 `gifts-book-server.exe` 使用即是设计形态。

## 🧩 技术栈

* **Core**: Vanilla JS (ES6+), OOP 架构
* **Style**: Tailwind CSS
* **Database**: IndexedDB (idb wrapper)
* **Crypto**: CryptoJS (AES-256)
* **Export**:
  * `SheetJS` (Excel)
  * `PDF-Lib` & `Fontkit` (客户端 PDF 生成)
* **UI Components**: Grid.js (表格), RemixIcon (图标)

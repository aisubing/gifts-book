# 电子礼簿 · 用户使用说明

一款在**自己电脑上运行**的礼金记账工具：现场录入宾客礼金、自动查重、语音播报、副屏展示，结束后一键导出 Excel/PDF 归档。数据全部保存在本机，不经过任何服务器。

---

## 一、快速开始

1. 解压收到的压缩包（如 `gifts-book-complete-v1.3.2.zip`）到任意文件夹；
2. 打开 `gifts-book` 文件夹，**双击 `gifts-book-server.exe`**——会自动启动并打开浏览器进入系统；
3. 如果 Windows 弹出"SmartScreen 已保护你的电脑"，点 **更多信息 → 仍要运行**（程序未做付费签名，属正常提示）。

> 请务必通过上面的 exe 运行，不要直接双击 `index.html`：直接打开时系统会拒绝启动，因为数据得不到自动备份保护。

**几个文件夹说明：**

| 位置 | 作用 |
|---|---|
| `gifts-book-server.exe` | 系统入口，每次使用都从它启动 |
| `gifts-book-makebin.exe` | 礼单转换工具（见第五节，可选） |
| `data/`（运行后自动生成） | 自动备份文件夹，**不要手动删除** |

## 二、创建事项（首次使用）

1. 在创建页填写**事项名称**（如"张府婚礼"）和**管理密码**；
2. 再次输入密码确认后，点"创建并进入"。

⚠️ **管理密码就是数据加密钥匙，丢失无法找回！** 请把密码写在纸质本子上妥善保存。忘了密码，这份礼簿（含备份文件）将永远打不开。

## 三、日常记账

* 录入区输入**姓名 → 金额**，选收款方式（现金/微信/支付宝/其他），回车即录入，全程键盘操作；
* 遇到**同名或同额**宾客，系统会自动提醒确认，防止记重；
* 金额自动生成中文大写（如"壹仟元整"），可在设置中开启**语音播报**，现场念出"××× 贺礼 一千元整"方便宾客核对；
* 备注可记录礼品、关系、电话、住址；
* 家里有电视/另一块屏幕？功能开启**副屏**后，主屏记账、副屏实时展示（自动隐私打码），还能展示东家收款码。

## 四、数据安全（重要）

系统为你做了三层保护，但**最后一步永远是自己导出存档**：

1. **自动备份**：每笔记录约 3 秒后自动加密备份到程序旁的 `data/` 文件夹。换浏览器、换端口、清了浏览器数据都不怕——用**相同的事项名和密码**重新进入，数据自动还原；
2. **手动备份**：左下"立即保存备份"可随时强制落盘一次；
3. **导出存档（必做）**：礼簿记好后，**第一时间**导出三样存档——**导出为 Excel**、**打印/另存为 PDF**，以及"备份/恢复数据"里的 **导出备份 (BIN)**——把文件发微信收藏或存网盘。本工具定位是现场记账，不建议长期把它当数据库，导出的存档才是最终归档。

**删除事项**前系统会强制你先导出 Excel，确认后才会删除。

## 五、礼单生成器（把纸质/外部礼单变成电子礼簿）

手里已经有一份现成的礼单（比如别人转发的 Excel、之前活动的表），想整体导入系统？用包里的 `gifts-book-makebin.exe`：

1. 双击打开，按提示操作：
   * 第一步：选择礼单文件——**直接支持本系统"导出为 Excel"生成的 .xlsx**，会自动跳过空行、末尾"总计"行和"已作废"记录；也支持 UTF-8 编码的 CSV（Excel 另存为"CSV UTF-8"）；
   * 第二步：起一个事项名称；
   * 第三步：设置管理密码（导入后即该事项的密码，**务必牢记**）；
   * 完成后会在同目录生成 `事项名称.bin` 文件。
2. 回到礼簿系统，创建页点 **"选择 .bin 备份文件导入"**，选中刚生成的文件、输入密码，整套礼单就导入为一个新的电子礼簿了。

## 六、常见问题

**问：忘记管理密码怎么办？**
无法找回。数据是加密的，这是设计使然。只能重新建事项重录，所以密码一定要抄在纸上。

**问：我的数据存在哪里？会不会上传网络？**
记账数据加密存在浏览器本地；`data/` 文件夹里是加密的备份副本。全程不联网传输，换电脑时把整个 `data/` 文件夹和程序一起拷走，或用导出的 Excel/BIN 文件即可迁移。

**问：双击 exe 后浏览器没自动打开？**
看程序窗口里显示的地址（一般是 `http://127.0.0.1:8765`），手动在浏览器输入即可；端口被占用时会自动换空闲端口，以窗口显示为准。

**问：可以两台电脑一起用吗？**
各自记各自的事项没有问题。但 `data/` 备份文件夹如果是共享的（如放在同一块共享盘），请只在其中一台电脑上运行系统，避免备份互相覆盖。
